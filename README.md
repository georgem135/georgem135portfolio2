# Hospital Emergency Room Analysis | Power BI

## Overview

This is an interactive Power BI report focused on hospital emergency room data. I built it as a portfolio project to practise presenting healthcare-related information in a clear visual format and make the report easier to explore than a raw table.

**[Open the interactive Hospital Emergency Room Analysis dashboard](https://app.powerbi.com/view?r=eyJrIjoiYThkNThmMDctOWYxZS00NWNlLWFiMWEtNmYyOTFiZGJjZGMwIiwidCI6ImVhMjk1OTFmLWRkZjItNDI3OS1hZmY3LTYxODdjMWI3MDBlZiJ9)**

## Project aim

The aim is to organise the information in the report so a viewer can explore the emergency room data and review the patterns shown by the available visuals.

## Tool

- **Power BI** — interactive report and data visualisation
